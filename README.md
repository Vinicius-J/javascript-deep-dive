# 📙 Javascript Deep Dive

![Node](https://img.shields.io/badge/node.js-18+-green) ![License](https://img.shields.io/badge/license-MIT-green) ![Status](https://img.shields.io/badge/status-active-success)

Estudo aprofundado de **Javascript** focando nos conceitos mais avançados buscando um entendimento maior sobre como funciona a linguagem.

Este repositório tem como objetivo aprender sobre a linguagem e ter um conteúdo próprio para pesquisar em momentos de dúvida.

---

# 📦 Clonando o projeto

Clone o repositório:

```bash
git clone https://github.com/Vinicius-J/javascript-deep-dive.git
```

Entre na pasta do projeto:

```bash
cd javascript-deep-dive
```

---

# 📥 Instalando dependências

Instale as dependências do projeto:

```bash
npm install
```

ou

```bash
yarn install
```
